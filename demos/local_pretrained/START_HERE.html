まず、PCだけで試す

機材の購入や配線より先に、映像と認識を確認できます。Windows＋Python 3.12の64bit版を基本とした手順です。

  1. ZIPをすべて展開し、Python 3.12を導入する。
  2. 00_install.bat を開く。初回はライブラリと学習済みモデルの自動取得にネット接続を使う。
  3. EOS RPをUSB接続し、EOS Webcam Utility Proを起動する。内蔵カメラでも試せる。
  4. 01_camera_setup.bat を開く。0〜4キーでカメラを選び、映像が出たら S で保存。
  5. 04_start_demo.bat を開く。ポート入力は空欄のままEnter。
  6. 対象物を1個ずつ見せる。画面の認識枠と DRY RUN: POINT ... が出たらPC側の確認は完了。

EOS RPの映像がOpenCVから読めるかは、お手元のOS・仮想カメラの組み合わせで確認が必要です。詳しい対処は 日本語の全手順 に記載しています。

配線は、信号・電源・GND

使用するのはピン取り付け済みPico Hと、通常の角度制御SG90です。配線時はUSBと電池を外します。

接続する線接続先
SG90の信号（橙／黄）Picoの GP15＝物理20番ピン
SG90の電源（赤）単3アルカリ電池3本ケースの＋
SG90のGND（茶／黒）電池ケースの−
電池ケースの−と同じ接続点Picoの GND＝物理23番ピン
Picoのmicro-USBPC。給電と通信を兼ねる

モーターは電池から給電します。電池の＋をPicoの3V3へつながないでください。小さいブレッドボードは電源線の分岐用です。

Picoへの書き込みと位置合わせ

  1. 電池スイッチをOFFにし、矢印を付ける前のPicoを準備する。
  2. BOOTSELを押しながらUSB接続する。Pico用MicroPythonのUF2をRPI-RP2ドライブへコピーする。
  3. USBを差し直す。02_copy_to_pico.bat を開き、一覧からPicoのCOMポートを入力する。2ファイルがコピーされる。
  4. もう一度USBを差し直し、電池をON。03_calibrate.bat でCを入力して中央へ動かす。
  5. 電池をOFFにして軽い紙の矢印を取り付ける。再度ONにしてL/C/Rを確認する。EOS RPは別の台に固定し、サーボには載せない。
  6. 04_start_demo.bat を開き、今度はCOMポートを入力する。

左右が逆ならconfig.jsonのleft/right角度を交換します。角度は30〜150の範囲に制限。実際の向きはサーボと取り付けに合わせて校正します。

2つの見せ方

① 種類で指す：meter

ボトル→左、カップ→中央、バナナ→右。見せる物を変えると、AIの判断に合わせて矢印が動きます。対象は1個ずつ見せます。

② 場所を探して指す：locate

Mで切り替えます。同じボトルを左右へ移し、場所に合わせて矢印が変わる様子を見せます。物は画面の3つの領域の中央寄りに置きます。

キー操作
Space一時停止／再開
M種類で指す／場所を探す
1 / 2 / 3探す物をボトル／カップ／バナナに切り替え
Q / Esc終了

認識なしや複数対象は保留。認識が約1.2秒消失したらPWM信号を止めます。USB指令が約2秒止まった場合もPicoが信号を止めます。電源そのものを切るときは電池ケースをOFFにします。

学習データはダウンロードする？

実演のためには不要です。自動取得するONNXファイルが「既存データで学習した結果」です。

教材として画像と正解ラベルも見たい場合は、download_examples.pyで小さなCOCO8を取得できます。ごみ分類の学習実習にはTrashNetもありますが、今回は学習工程を省きます。

vlm_demo.pyを用意しています。こちらも追加学習は不要ですが、画像対応AIのAPIキー、インターネット、利用枠・料金の確認が必要です。

python vlm_demo.py --port COM5 --instruction "文字を書く道具を教えて"

3つの領域にペン・飲料ボトル・ティッシュなどを置き、Spaceで画像と指示を1回だけ送ります。回答と動作が終わるまで物を動かさず、Sで停止します。

ローカル版と異なり、画像は外部APIへ送信されます。このAPI版の実接続は未検証です。モデルIDは利用できるものを指定できます。
