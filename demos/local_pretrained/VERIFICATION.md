# 検証記録

2026-10-17。Python 3.12.14 / Linux x86_64、OpenCV 4.12.0.88、NumPy 2.2.6、pyserial 3.5、mpremote 1.26.1で確認。

## 確認できたこと

- 自動取得するYOLOX-sモデルはOpenCV Zooの元ファイルとSHA256が一致。
- 学習・重みの変更を行わず、OpenCV DNNのCPU推論でCOCO8全8画像を処理。7画像で1件以上の検出、1画像で検出なし。
- COCO128の正解ボックス周辺を切り出した実画像から、ボトル・カップ・バナナをそれぞれ認識。
  - bottle: 000000000283.jpg
  - cup: 000000000605.jpg
  - banana: 000000000142.jpg
- 以上はモデルファイルと前処理・後処理の動作確認。切り出し画像を選んだスモークテストであり、独立した精度評価ではない。
- 判定スコアを出しているが、正解確率の校正や、手元の実物での精度を保証する値ではない。
- 制御・接続境界に関する11テストを実行。
  - 複数対象、低信頼度、小さすぎる対象、対象外クラスで指示を保留。
  - 観測が揺れる場合は指示を確定せず、一定時間・複数観測で確定。
  - 対象消失と長い観測間隔の扱い。
  - 角度範囲外や不正なUSB指令の拒否。
  - 実際に配布するpico/main.pyを、模擬のGPIO・時計・USB入力で実行し、起動時のPWM停止と約2秒の通信断停止を確認。
  - USBの初期応答、終了時STOP、VLM返答の選択肢制限。
- tools.py checkの実行、モデルの整合性検査、Pythonファイルの構文を確認。
- COCO8の公開配布URLと取得スクリプトを実際に使用して確認。

詳細は verification_model_results.json / verification_target_results.json。
公開画像は本ZIPへ再配布せず、画像IDと検出結果だけを記録した。
