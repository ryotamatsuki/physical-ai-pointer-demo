# EXP-001 — Pico basic test

## Objective

Raspberry Pi Pico HへMicroPythonを導入し、PCからコードを実行してオンボードLEDを制御できることを確認する。

## Pass criterion

LEDが0.5秒ON / 0.5秒OFFで安定して10周期以上点滅し、Picoが再起動しない。

## Status

NOT STARTED

## Procedure

1. SG90は接続しない。
2. BOOTSELを押しながらPico HをUSB接続。
3. ThonnyからMicroPythonを導入。
4. Shellで `print("Hello Pico")`。
5. LED blinkコードを実行。
6. 10周期以上観察。
7. 結果とMicroPythonバージョンを記録。
